# Delivery pipeline

This project defines the Pulumi Delivery pipeline. It watches the `repository` and `branch` set in its config and starts a run on every push that changes a file under `path`, this example's directory; a push that changes this directory also updates the pipeline itself. The `build` stage runs the [image](../image) stack with the commit, and the `beta` stage runs the [beta](../beta) stack with the image stack's `imageRef` output. After the beta stack, the `check-url` job runs [`check-url.sh`](check-url.sh) until the app answers, and the release records the app's URL as its `beta-url` artifact. It uses the [`pulumi-delivery`](https://pypi.org/project/pulumi-delivery/) package from PyPI; see the [example's README](../README.md) to set it up.
