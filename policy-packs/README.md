# Example policy packs

Examples of Pulumi [Policy as Code ("CrossGuard")](https://www.pulumi.com/docs/guides/crossguard/) policy packs. For more on Policy as Code, visit the [Pulumi Policy repo](https://github.com/pulumi/pulumi-policy).

This directory contains the following policy packs:

- [stackvalidation-ts/](./stackvalidation-ts) — a stack validation policy written in TypeScript.
- [stackvalidation-python/](./stackvalidation-python) — a stack validation policy written in Python.
